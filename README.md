# BroGame — موقع المحل والحجوزات

موقع BroGame (ميزيتلي / ميرسين) مع حجز أونلاين لـ PS5، سيمولاتور السيارات، البلياردو والبينغ بونغ.

## الروابط

- الموقع والحجز: https://otillion.github.io/brogame/
- حجوزاتي (للزبون): https://otillion.github.io/brogame/#my
- لوحة المالك: https://otillion.github.io/brogame/#admin (بس بحساب `broogame10@gmail.com`)
- بطاقة الولاء Game Kart: https://otillion.github.io/brogame-kart/

## لوحة المالك

- **الجدول**: كل الوحدات وكل الساعات. اكبس على ساعة فاضية بتنسكّر (زبون بالمحل)، واكبس مرة تانية بتنفتح. اكبس على حجز لتشوف الاسم والرقم أو تلغيه.
- **الحجوزات**: قائمة حجوزات اليوم مع أرقام التلفونات.
- **الإعدادات**: أوقات الدوام لكل يوم، سعر الساعة لكل قسم، زيادة/حذف وحدات، تسكير وحدة، وقواعد الحجز. بعد أي تغيير اضغط "احفظ".

## كيف مبني

- الاستضافة: GitHub Pages (هالمستودع).
- تسجيل الدخول والبيانات: نفس مشروع Firebase تبع Game Kart (`brogame-kart` على حساب broogame10، خطة Spark المجانية).
- `firestore.rules`: قواعد الحماية لكل النظامين (Game Kart + الحجوزات). نسخة منها منشورة بـ Firebase Console → Firestore → Rules.

## الحماية

- ما في حجزين على نفس الوحدة بنفس الساعة (كل ساعة إلها مستند واحد، وقاعدة البيانات بترفض التكرار).
- الزبون بيشوف ويلغي حجوزاته بس، وما حدا غيره بيشوف رقمه.
- بس صاحب المحل بيعدّل الإعدادات ويسكّر ساعات ويلغي أي حجز.
